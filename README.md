## About the Project

This project was developed as part of Web Technologies Assignment 6. The main purpose is to practice using jQuery for selecting HTML elements, navigating through the DOM, modifying webpage content, and creating animations.

The project is based on a birthday party mystery. Guests are distributed across four rooms in a house, and each guest has different information, including their name, clothing color, arrival time, AITU student status, and personal belongings.

The webpage allows users to investigate different cases and interact with the guests through animations and visual effects.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
- DiceBear Open Peeps Avatars

## Project Features

### Task 1 – Selector Detective

- Displays four rooms on two floors.
- Generates guest cards dynamically from JavaScript data.
- Shows guest avatars, names, arrival times, clothing colors, belongings, and AITU badges.
- Includes 20 investigation cases.
- Uses jQuery selectors and DOM traversal methods to find matching guests.
- Highlights investigation results and displays the number and names of matching guests.
- Adds Miras to the party using `fadeIn()`.
- Removes Natasha using `fadeOut()`.

### Task 2 – The Party in Motion

- **Spotlight Effect:** Highlights matching guests and fades other cards.
- **Guest Information Card:** Opens an animated card with complete guest information.
- **Move Guests:** Allows guests to move between rooms with animation.
- **Sort by Time:** Arranges guests according to their arrival time and restores their original order.
- **Fast Click Handling:** Uses animation controls to prevent unnecessary animation queues.

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/amanislami1385/Assignmnet-6-Web.git
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure the following files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`

4. Install the Live Server extension in Visual Studio Code if it is not already installed.

5. Open `index.html` and click **Go Live** in the bottom-right corner.

6. The webpage will open in your browser.
